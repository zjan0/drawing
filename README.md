# drawing
navod k pouziti: nahore jsou nastroje jako guma, stetec, kbelik, tri typy car, kruh, ctverec, trojuhelnik, kruh, polygon
dale tam je vyber tlousky car mezi 1-20, obri ctverec kde je soucasna barva, a barvy na vyber a paleta
velikost gumy je 5*krat vetsi, kbelik seka, modifikace car po nakresleni neni, kdyz clovek vyjede z platna tak to prestane rasterizovat
pro novy polygon kliknete cokoliv krome barev a sirky, rovnomerne(shift) pro vse krome polygonu, e pro smazani platna
